Identifying and classifying information and assets is a critical first step in developing an
effective security program. This process involves categorising data and assets based on their sensitivity, criticality, strategic, and monetary value to the organisation.
- Prioritise security measures
- Facilitates compliance
- Streamlines access controls
- Improves Incident Response
- Reduces risk of Data Loss

Common types of sensitive data:
- PII / SPII - Personally Identifiable Information
- PHI - Protected Health Information
- PFI - P???? Financial Information
anonymisation vs pseudonymous

Key consideration for data classification include:
- Gathering requirements
- Classification scheme
- Data labelling 
- User training
- Maintenance
