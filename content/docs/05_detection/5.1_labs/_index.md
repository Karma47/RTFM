##### Topic: Hypothesis Driven Threat Hunting
**Duration: 4.5 Hours**

**Description:** This Threat Hunting workshop is designed to provide participants with practical experience in identifying, investigating and analysing suspicious activities using a SIEM platform.

Participants will work within a preconfigured environment containing artificially generated security logs that simulate realistic cyber incidents.

Through guided and independent investigation exercises, participants will learn the following:
1. Develop threat hunting hypotheses
2. Analyse security events
3. Correlate logs from multiple sources
4. Identify IOCs and IOAs
5. Reconstruct incident timelines.

The workshop will follow a scenario-based approach, where participants act as Threat Hunters investigating a suspected security incident within a simulated enterprise environment using a Threat Intelligence Report.

# Null National Bank

## Security Operations Centre – Threat Hunting Exercise

Welcome to the Null National Bank cybersecurity exercise.

You have been assigned to the Security Operations Centre (SOC) investigation team.

Your objective is to investigate suspicious activity across the bank's hybrid infrastructure, identify attacker activity, and uncover evidence of compromise.

### Exercise objectives

- Investigate suspicious authentication activity.
- Identify compromised user accounts.
- Detect malicious execution and persistence.
- Investigate privilege escalation.
- Identify lateral movement.
- Determine the extent of the compromise.

### Exercise environment

The exercise simulates a hybrid enterprise environment containing:

- Active Directory infrastructure
- Windows workstations and servers
- Internal file and application servers
- DMZ-hosted web, database and mail servers
- Centralised Splunk SIEM
